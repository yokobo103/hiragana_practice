# なぞりん（ひらがな・カタカナ）

指でかなをなぞって覚える、子ども向けの練習アプリ（試作v3）。
書いた線はそのまま残り、お手本との似ぐあいで点がつく。
ビルド不要の素のHTML/CSS/JS。スマホ・タブレット縦持ち前提。

## うごかす

```bash
python -m http.server 8143 --directory app
```

ブラウザで <http://localhost:8143> を開く。

## 遠隔テスト

Node.js 24 と Python 3 を用意して、依存関係を入れる。

```bash
npm ci
```

別のターミナルで `npm run serve` を起動してから、検査を実行する。

```bash
npm test
npm run test:mobile
```

GitHubへpushすると、同じデスクトップ／モバイル検査がGitHub Actionsでも自動実行される。

## できること

- **ひらがな / カタカナ** を切り替えて、50音表から字を選ぶ
  （ひらがな81字・カタカナ82字。清音46・だくおん25・ちいさいじ、カタカナは「ー」も入る）
- **書き順どおりに1画ずつなぞる**。指が通った道がそのまま線として残る
- 1画おわるたびに ★の数と「いいね！／じょうず！／かんぺき！」＋音、
  全画そろうと「ずかんに はいった！」＋紙ふぶき＋読み上げ
- 字ごとに**いちばん良かったときの★**が 表と ずかんに出る
- **おてほん**ボタンで書き順を再生。3.5秒とまると書きはじめの丸が光る
- 効果音はWebAudioの合成。音源ファイルは0バイト。最初のタップでAudioContextを起こす
- 読み上げはブラウザのSpeechSynthesis（ja-JP）。無い環境では黙るだけ

## 報酬のしくみ（ずかん）

背骨は **「なぞった字の"ことばの絵"が ずかんに増える」**。

- **1字なぞる = ずかんの1マスが開く**。「あ」をなぞると 🐜あり が出る。
  まだの字は **？** でふせてある（絵を先に見せない。開けたいが次をなぞる動機になる）
- **1ページ = 五十音の1行**。あ行5字がそろうと **「あ行 かんせい！」** のごほうび画面が出て、
  5つの絵が並び、ずかんのページに「かんせい🎉」の帯がつく
- ずかんの絵はどれもタップでその字のなぞり画面へ飛べる。もどるとずかんに帰る
- 進みぐあいは3か所に出る:
  表の `⭐ n / 46` / ヘッダの `📖 n`（ひらがな＋カタカナの合計） / ずかんの `n / 81`

ページは必ず2字以上にしてある（`pagesOf`）。1字だけのページで「かんせい！」が出ると、
ごほうびが安くなるため。カタカナの「ー」は単独ページにせず「ちいさいじ 2」に混ぜている。

例のことばと絵文字は `app/js/words.js` の `WORDS` 一箇所。ここを直せば ずかんの中身も変わる。

## 判定のしかた（お手本との似ぐあい）

**書いた線はそのまま残る。**指が通った道をそのまま描いて、合格したらその線が字になる。
完成した字は「子どもが書いた線」でできていて、お手本の形をなぞり返したものではない。

判定は書き終わってから、**お手本との距離**で採点する。

| 見るもの | 中身 |
|---|---|
| かたち (45%) | お手本の各点から、自分の線までの距離の**平均** |
| きれいさ (35%) | 自分の各点から、お手本までの距離の**平均**（はみ出した分だけ下がる） |
| むき (20%) | 書きはじめ・書きおわりが お手本と合っているか |

平均のズレが `D0`（既定8）に達するとその項目は0点。109の字の中で平均8ずれる＝
画面で25pxくらいで、かなりガタガタな線。

点数 → ★の数は **85点以上=★★★ / 70点以上=★★ / それ未満=★**。
実測（`node tools/verify.mjs` が毎回出す）:

```
ふるえ± 0 → 100点 ★★★   手本からの平均ズレ 0.0
ふるえ± 4 →  88点 ★★★   手本からの平均ズレ 1.2
ふるえ± 8 →  77点 ★★☆   手本からの平均ズレ 2.3
ふるえ±12 →  67点 ★☆☆   手本からの平均ズレ 3.1
ふるえ±16 →  58点 ★☆☆   手本からの平均ズレ 3.8
```

**合格ライン自体はゆるい。**上の5つは全部合格する。★の数で上手さを見せて、
やりなおしになるのは「これは別の線」というときだけ:

| 理由 | 出る言葉 | 条件 |
|---|---|---|
| `reverse` | はんたいから かいてるよ | はじめと終わりが お手本と逆 |
| `off` | せんの うえを なぞろう | 自分の点の55%以上が お手本から16以上離れた |
| `start` | はじめの ●から なぞろう | 書きはじめに17以内で近づいていない |
| `short` | さいごまで なぞろう | 書きおわりに届いていない／途中がごっそり抜けた |

やりなおしのとき、**書いた線は薄い赤で0.5秒残ってから消える**。
何を書いたのかを見せないと、どこが違ったのか分からないため。
ただのタップ（線の長さが6未満）は黙って捨てる。怒られない。

書き順は「今なぞる画」を1画ずつ進めることで守らせる。2画目を先に書いても
今の画として採点されて落ちる。

### つまみ（`app/js/tracer.js` の先頭）

| 定数 | 既定 | 意味 |
|---|---|---|
| `D0` | 8 | 点数の物差し。**大きいほど点が甘い** |
| `R_STRAY` | 16 | 「線の上」と認める距離（`off` の判定に効く） |
| `R_END` | 17 | 書きはじめ・書きおわりに「届いた」と認める距離 |
| `R_COVER` | 13 | 「なぞられた」と認める距離（途中抜けの判定） |
| `PASS` | — | やりなおしにする境目。ここを下げるともっとゆるくなる |

「もっとゆるく」なら `D0` を大きく、`PASS` を下げる。「もっとちゃんと」なら逆。

## スマホでの動き

配って遊んでもらう前提なので、指で触ることを先に測っている。

- **入力はPointer Events**。指・ペン・マウスを同じ道で扱う。`touch-action:none` と
  `touchstart` の `preventDefault` で、なぞり中にページが動かないようにしてある
- **2本目の指と手のひらは無視する。**書きかけの線が乗っ取られると「書いたのに消えた」に
  なって、子どもには理由が分からない
- **`pointercancel` は採点しない。**着信やシステムのジェスチャで取り上げられただけなので、
  やりなおしの注意も出さない
- 指の的はぜんぶ44px以上。二本指ズーム・ダブルタップ拡大・引っぱって更新は塞いである
- 画面下の安全域（`env(safe-area-inset-bottom)`）を見てボタンを浮かせている
- **よこ向きのときはボタンを右の列へ逃がす**。たてに積んだままだと書くマスが潰れる
  （844x390で 243px → 312px）
- 最初のタップで AudioContext を起こす（iOSは無音のままになるため）
- `manifest.webmanifest` とアイコンを置いてあるので、**ホーム画面に置くとフルスクリーンで開く**

### スマホ検査

```bash
node tools/verify_mobile.mjs
```

`verify.mjs` はマウスで動かしている。こちらは **CDPの本物のタッチイベント**で指を動かし、
5つの画面サイズ（iPhone SE / iPhone 14 / Android / iPad / よこむき）で65項目を測る。
絵は `work/qa-mobile/` に出る。

測っているのは: 横にはみ出さないか / ページ自体がスクロールしないか / 指の的が44px以上か /
書くマスがボタンやヘッダと重ならないか / **指で実際に字が書けるか**（`pointerType` が
`touch` であることも見る）/ **手のひらが触れても1画目が通るか** / 回しても崩れないか /
ホーム画面に置けるか（マニフェストとアイコンが200で返るか）。

アイコンは `node tools/make_icons.mjs` で作る（SVGをヘッドレスChromeでPNGに焼くだけ。
画像ツールを入れなくていい）。

## 検査

```bash
node tools/verify.mjs
```

ヘッドレスChromeがマウスで実際に字を書いて、43項目を測る。
画面の絵は `work/qa/` に出る（画面が出ない環境でも詰められる）。

**ふるえは線に対して直角に入れる。**線に沿ってずらしても お手本から離れないので、
「±16でなぞった」と書いてあるのに実際は2しか離れていない、という測り方になってしまう。

測っているのは:

- 下手さと点数の対応表（上に載せたもの）。**下手になるほど点が下がるか**、
  **上手・下手で30点以上ひらくか**、★3がていねいなときだけか
- やりなおしの4つの理由が それぞれ正しく出るか（逆向き／はみ出し／途中から／途中まで）
- 残っているのが**指の道**か（お手本の形のコピーでないことを距離で確かめる）
- ただのタップが無視されるか / やりなおしのあと書き直せば進むか
- カタカナ（「ー」を含む）を最後まで書けるか
- ずかんがふせてあるか、なぞると開くか、行がそろうとごほうびが出るか、★が出るか
- 178字ぶんのデータと、表の字のことば・形がそろっているか
- **ヘッダのボタンが横に伸びていないか**（CSSのクラス名衝突は静かに壊れる）

## 構成

```
app/
  index.html
  css/style.css
  js/main.js      画面遷移・ずかん・ごほうび・スタンプ帳・紙ふぶき
  js/tracer.js    なぞり判定＋canvas描画（本体）
  js/audio.js     効果音の合成
  js/words.js     例のことば・50音表のならび・ずかんのページ割り
  data/kana.js    178字ぶんのストロークデータ（自動生成）
  manifest.webmanifest
  icons/            ホーム画面用アイコン（自動生成）
tools/
  fetch_kanjivg.py  KanjiVGからSVGを取得
  build_data.py     SVG → kana.js
  verify.mjs        ヘッドレス調整ハーネス（マウス）
  verify_mobile.mjs スマホ検査（本物のタッチ・5サイズ）
  make_icons.mjs    アイコンを焼く
work/
  kanjivg/    取得した生SVG
  qa/         検査で撮った画面
  qa-mobile/  スマホ検査で撮った画面
```

`app/data/kana.js` は**手で編集しない**。作り直しは:

```bash
python tools/fetch_kanjivg.py && python tools/build_data.py
```

## まだやっていないこと

- 書いた筆跡は ずかんに保存していない（毎回きれいな絵文字が出る）。
  「じぶんが書いた字のアルバム」にはできる
- 濁点・半濁点は「が」の3画目のように**1字まるごと**なぞる（点だけ足す練習はない）
- 数字・アルファベットは未対応
- 「ことばを作る」段階（あ→り→ で「あり」）は無い。1字ずつの練習まで
- ずかんの絵はぜんぶ絵文字。ラボの3Dアセットやニャビットには差し替えていない
- **実機（iPad / iPhone）での試遊は未実施。**測っているのはヘッドレスChromeの
  タッチ再現までで、本物のiOS Safariでは触っていない
- オフライン対応（Service Worker）は入れていない。電波が切れると開けない
- 配信していない
